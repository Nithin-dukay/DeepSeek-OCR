# MSN

This document provides information about the project.

## Overview

This is a DeepSeek OCR project that provides optical character recognition capabilities.

## Features

- OCR processing using DeepSeek models
- Support for various image formats
- Batch processing capabilities
- Integration with HuggingFace and vLLM
