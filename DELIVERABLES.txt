================================================================================

PROBLEM: 9.2% catastrophic failure rate (loops/duplication) on 600 historical
newspaper images, plus API usability issues (infer() stdout-only, missing
chat_template, no generate() examples).

SOLUTION: Comprehensive toolkit with 8 production-ready files (~100KB total)

QUICK START
================================================================================

# 1. Install dependencies (same as Issue #151 environment)
pip install torch==2.6.0 transformers==4.46.3 tokenizers==0.20.3 Pillow numpy

# 2. Use enhanced inference
from enhanced_hf_inference import EnhancedDeepSeekOCR

model = EnhancedDeepSeekOCR()
result = model.infer_with_retry(
    image='historical_newspaper.jpg',
    detect_repetition=True
)

if result['success']:
    from text_extraction_utils import get_text_only_output
    clean_text = get_text_only_output(result['text'])
    print(f"Success! Text length: {len(clean_text)}")

================================================================================
RECOMMENDED SETTINGS
================================================================================

For historical newspapers (Issue #151 use case):

Standard (first attempt):
  base_size=1024, image_size=640, crop_mode=True
  max_new_tokens=3072, no_repeat_ngram_size=6, repetition_penalty=1.2

Stricter (retry):
  base_size=1024, image_size=640, crop_mode=True
  max_new_tokens=2048, no_repeat_ngram_size=7, repetition_penalty=1.3

For tall documents (height/width > 1.5):
  max_new_tokens=2048, no_repeat_ngram_size=7, repetition_penalty=1.3
