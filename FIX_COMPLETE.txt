PROBLEM
------------------------------------------------------------------------
System crashes when processing large PDFs (2800+ pages) on AWS EC2 g5.2xlarge
- Environment: Ubuntu x86_64, NVIDIA A10 (24GB VRAM)
- Works: 400-page PDF (~1 minute)
- Fails: 2800-page PDF (system crash, no logs)

ROOT CAUSE
------------------------------------------------------------------------
1. Entire PDF loaded into memory at once
2. No memory cleanup between operations
3. PyTorch tensors and PIL images accumulated
4. GPU cache never cleared
5. All output images stored before writing
