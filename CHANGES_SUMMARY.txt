================================================================================
USAGE
================================================================================

1. Install dependencies:
   pip install psutil

2. Configure (optional):
   Edit config.py to adjust PDF_BATCH_SIZE based on GPU memory

3. Run processing:
   cd DeepSeek-OCR-master/DeepSeek-OCR-vllm
   python run_dpsk_ocr_pdf.py

4. If interrupted, simply re-run - it will resume from checkpoint
