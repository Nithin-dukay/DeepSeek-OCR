PROBLEM:
--------
ModuleNotFoundError: No module named 'torch' when installing xformers

ROOT CAUSE:
-----------
xformers requires torch to be installed BEFORE it can build from source.
pip tries to install all dependencies together, causing xformers to fail.

SOLUTION:
---------
Install PyTorch FIRST, then vLLM (which includes xformers).

QUICK FIX:
----------
1. pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu118
2. pip install vllm-0.8.5+cu118-cp38-abi3-manylinux1_x86_64.whl
3. pip install -r requirements.txt
4. pip install flash-attn==2.7.3 --no-build-isolation
