THE FIX (Technical):
================================================================================

The core fix for Issue #244 is registering the model with vLLM:

    from vllm import ModelRegistry
    from deepseek_ocr import DeepseekOCRForCausalLM
    
    ModelRegistry.register_model("DeepseekOCRForCausalLM", DeepseekOCRForCausalLM)

This tells vLLM how to instantiate the custom DeepseekOCRForCausalLM architecture.

The serve_deepseek_ocr.py script does this automatically.
