================================================================================
                         PATTERN MATCHING EXAMPLES
================================================================================

Pattern: r'\b[a-zA-Z]\s+(\d+)'
         └─┬─┘ └┬┘ └┬┘ └──┬──┘
           │    │   │     │
           │    │   │     └─ Capture group: one or more digits
           │    │   └─────── One or more whitespace characters
           │    └─────────── Single letter (a-z or A-Z)
           └──────────────── Word boundary

Matches:
  "s 331"  → captures "331"
  "a 100"  → captures "100"
  "x 50"   → captures "50"

Does NOT match:
  "331"    → no letter prefix
  "s331"   → no space
  "ss 331" → two letters (not single)
